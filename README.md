# Быстрый список / QuickList

Простые списки покупок и дел с виджетом на главном экране. Без аккаунта и без интернета, все данные хранятся только на устройстве.
(English version: README.en.md)

## Как открыть в Android Studio
1. Android Studio Koala (2024.1) или новее → **File ▸ Open** → выберите папку `QuickList`.
2. Дождитесь синхронизации Gradle (нужен JDK 17+; Android SDK 34 студия предложит установить сама).
3. Запустите модуль `app`.

## Возможности
- Любое количество списков двух видов: **Покупки** и **Дела**
- **Быстрый ввод**: клавиатура открывается вместе со списком, несколько записей добавляются через запятую
  - `молоко х2`, `2 молока`, `1,5 кг яблок`, `молоко 2л` — количество распознаётся
  - `позвонить маме!` — высокая важность (в делах)
  - голосовой ввод (кнопка микрофона)
  - подсказки из вашей истории, добавление одним нажатием
  - повторное добавление выполненной записи возвращает её вместо дубликата
  - на главном экране есть поле быстрого добавления с выбором списка
  - «Поделиться» текстом из любого приложения добавляет записи в последний список
  - ярлыки на иконке приложения: добавить покупку / добавить дело
- Покупки: количество, цена и итог, автокатегории (русские и английские ключевые слова), группировка по категориям
- Дела: важность, срок с уведомлением, повтор (каждый день / неделю / месяц), кнопка «Готово» в уведомлении
- Свайп для удаления с отменой, нажатие для редактирования, сворачиваемый блок «Выполнено»
- Сортировка, переименование, отправка списка текстом, снять все отметки, удалить выполненные
- **Виджет** (меняет размер): выбор списка, отметки прямо в виджете, кнопка «+» открывает список для ввода
- Тема светлая / тёмная / системная, динамические цвета (Android 12+), русский и английский язык
- Резервная копия: экспорт и импорт JSON (в настройках)

## Структура
```
app/src/main/java/com/quicklist/app/
  MainActivity.kt, QuickListApp.kt
  data/      сущности Room, DAO, Repository (в т.ч. бэкап), Prefs, Category
  util/      QuickParser (умный ввод), сортировка и форматирование
  reminders/ планировщик AlarmManager, получатели уведомлений и загрузки
  widget/    виджет на Glance, активность настройки
  ui/        экраны Compose, ViewModel, навигация, тема
```
Стек: Kotlin, Jetpack Compose (Material 3), Room (KSP), Glance, языки приложения через AppCompat. minSdk 26, targetSdk 34.

## Примечания
- Напоминания используют неточные будильники (спецразрешение не нужно): срабатывают в течение нескольких минут после выбранного времени.
- Виджет следует системной теме и цветам обоев (виджеты работают вне процесса приложения).
- Чтобы добавить язык: создайте `res/values-xx/strings.xml` и добавьте его в `res/xml/locales_config.xml`.
